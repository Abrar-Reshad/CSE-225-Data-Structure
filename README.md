# 📚 Data Structures in C++

This repository contains basic to intermediate-level implementations of **Data Structures** along with explanations and sample usage.

It is perfect for students, beginners, and anyone preparing for coding interviews or competitive programming.

---

## 🧩 Topics Covered

✅ Arrays  
✅ Linked Lists (Singly, Doubly, Circular)  
✅ Stacks  
✅ Queues (Normal, Circular, Priority)  
✅ Trees (Binary Tree, BST, Traversals)  
✅ Graphs (BFS, DFS, Adjacency Matrix/List)  
✅ Dynamic memory
